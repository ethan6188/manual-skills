# 设计要点

目标：让官网看起来像产品本身的延伸，而不是另一套模板。判断标准是「把官网里的窗口复刻和真实应用并排放，看不出两套系统」。

## 令牌

直接用 CSS 变量承载，深色靠 `prefers-color-scheme` 覆盖同一组变量，不写第二套选择器。下面是这次页面实际用的一组，系统灰阶加一个操作蓝：

```css
:root {
    --bg: #fff;
    --card: #f5f5f7;
    --text: #1d1d1f;
    --text-2: #6e6e73;
    --text-3: #86868b;
    --hairline: rgba(0, 0, 0, 0.08);
    --control-border: rgba(0, 0, 0, 0.12);
    --link: #06c;
    --accent: #007aff;
    --focus: rgba(0, 122, 255, 0.55);
}

@media (prefers-color-scheme: dark) {
    :root {
        --bg: #1e1e1e;
        --card: #2a2a2c;
        --text: #f2f2f2;
        --text-2: #aeaeb2;
        --text-3: #8e8e93;
        --hairline: rgba(255, 255, 255, 0.07);
        --link: #4da3ff;
    }
}
```

颜色纪律：每种颜色只表达一件事。蓝色只给可点击的操作；红色只给「正在记录」这类状态；橙色只给「需要注意」；绿色只给「已授权/已开启」。不在装饰里使用这些语义色。

## 排版

- 字体用系统栈，中文放在前面：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif`。
- 标题 600 字重，字距 `-0.02em`，首屏 `clamp(36px, 4.6vw, 56px)`，行高 1.22。正文 16px / 1.7，副文 18px，次要信息 13px。
- 行宽：副文限制在 30em 以内，段落 44em 以内。
- 标题里不做单词高亮、不全大写、不加装饰性小标签。

## 版面

- 内容容器宽 1120px，两侧留 24px；章节上下 112px，章节之间只用一条发际线分隔。
- 首屏两栏 5:6，左文右图，窄屏（小于 880px）改单列，隐藏锚点只留下载按钮。
- 圆角分层：窗口 12px，卡片 10px，功能区外框 16px，按钮 10px。不要所有东西同一个圆角。
- 阴影只给浮起的窗口一份；其余靠发际线。

## 产品窗口复刻

用 HTML 和 CSS 复刻界面，不用截图。原因：深浅色自动跟随、文字可选、放大不糊、没有图片体积。

- 窗口：1px 发际线边框 + 一层大而轻的阴影 + 12px 圆角；标题栏 44px，左侧三个交通灯。
- 内容用产品里真实的文案、真实的结构，数字和时间合理且自洽。
- 虚构的示例内容要在页面上标明是示例，或使用不会被当作真实数据的内容。

## 主角与动效

- 主角（吉祥物或核心状态）坐在窗口边缘，覆盖在窗口上方，宽约 160px。
- 状态切换同时更新三处：主角图、状态文字、录制指示点。按钮和主角本身都可点，切换时用 0.18s 的透明度过渡。
- 全页只留两处自发动画：录制指示点的呼吸，和主角的轻微上下浮动。其余动效只响应用户操作。
- 所有动画包在 `prefers-reduced-motion: reduce` 里关掉。

## 功能区的片段卡

- 外框：16px 圆角，浅灰渐变底，内嵌发际线；高度固定 300px，`overflow: hidden`。
- 里面的面板贴左上，左上圆角，右下被裁掉，底部 72px 渐隐到外框底色。这样看起来是「窗口的一角」，信息密但不拥挤。
- 卡片下方只有一个 20px 三级标题和一句 16px 说明，说明不超过 26em。

## 可访问性清单

- 所有交互元素有可见焦点：`:focus-visible { outline: 3px solid var(--focus); outline-offset: 2px; }`。
- 复刻的窗口用 `role="img"` 加一句 `aria-label` 描述，内部装饰元素不被读屏重复朗读。
- 按钮至少 44px 高（顶栏小按钮 32px 除外）。
- 状态文字用 `aria-live="polite"`。
- 图片装饰性的写 `alt=""`，有信息的写描述。
