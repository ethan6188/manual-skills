# 有品味的产品官网：怎么设计，怎么拒绝 AI 感

AI 做出来的页面有一眼就能认出来的味道：不是丑，而是「谁家都一样」。品味来自三件事：页面从产品本身长出来，只在一处下重笔，其余全部克制。下面是做法与自查办法。具体数值和写法见 [references/recipes.md](references/recipes.md)。

## 1. 先让页面从产品里长出来

- 先找产品自己的设计系统：颜色、字体、圆角、分隔线、深浅色。官网直接继承它们。没有就向用户要设计稿或截图，不要自己发明一套。
- 用户的要求如果已经规定了方向（例如「与应用风格一致」），照做。沿用系统灰阶是选择，不是偷懒。
- 页面里的界面、文案、数据都用产品里真实存在的东西。虚构内容要像真的，同时标明是示例。
- 想不出「这个页面是谁的」时，先停下。把产品名遮住，页面仍能被认出是它，才算过关。

## 2. 认出 AI 感的来源，逐条绕开

这些是生成页面最常见的套路。它们单独看都合理，问题是不管什么产品都长这样。

| 套路 | 替代做法 |
|---|---|
| 米色底加高反差衬线标题加陶土色强调 | 颜色和字体取自产品，不取自「看起来高级」的配方 |
| 近黑底加一个荧光绿或朱红强调色 | 强调色只给可点击的操作，数量克制 |
| 内容切成一排完全相同的圆角卡片，同一圆角、同一灰阴影 | 圆角按层级分（窗口、卡片、按钮各不同），阴影只给真正浮起的一个，其余用发际线 |
| 渐变光晕、渐变描边当装饰 | 没有信息的装饰一律删掉 |
| 每个标题上方一行全大写加宽字距的小标签 | 要标签就写进内容里，不要为了「像官网」加 |
| 标题里只给一个词换色、斜体或加粗 | 整句同一个样式，靠字号和字重分层 |
| 用 01 / 02 / 03 编号并不是流程的内容 | 只有真有先后顺序（安装步骤）才编号 |
| 元信息用「·」连接、标签写成「词 — 片段」、链接末尾加「→」 | 用标点之外的结构区分，用词而不是符号 |
| 等宽字体做所有小标签、纯黑用带色调的近黑 | 小标签用正文字体，黑就是产品里那个黑 |
| 每个区块进场淡入上滑、每张卡片悬停抬起 | 自发动画全页最多两三处，其余只响应用户操作 |
| 大数字加小说明加渐变，当作首屏 | 首屏放这个产品最有特征的东西（见下） |
| 「赋能」「一站式」「极致体验」这类空话；按钮写「提交」 | 说用户得到什么；按钮写动作本身，如「下载 Mac 版」 |

## 3. 品味的做法

**只在一处下重笔。** 选一个让人记住的元素，其余保持安静。这次是一只坐在应用窗口边缘的桌面宠物，点一下切换四种状态，状态文字和录制指示同步变化。它不是装饰，因为它就是产品的性格。选的元素要回答：这个产品独有的东西是什么？

**首屏放最有特征的东西。** 一句话主张加一段副文，旁边是产品窗口的 HTML 复刻和它的主角。不要用通用的插画或渐变球。

**用 HTML 画界面，不用截图。** 深浅色自动跟随，文字清晰可选，没有图片体积；更重要的是你必须把产品里真实的结构和文案想清楚才画得出来，这个过程会自动淘汰空话。

**功能区是「窗口的一角」。** 每个功能一个裁切过的界面片段加一个标题加一句话。片段贴左上、右下被裁掉、底部渐隐，信息密但不拥挤。一句话说不完的功能，说明还没想清楚。

**颜色各司其职。** 蓝色只表示可操作，红色只表示正在记录，橙色只表示需要注意，绿色只表示已开启。语义色不拿来装饰，页面立刻显得有章法。

**字体承担个性，而不是搬运内容。** 用产品的字体栈，靠字重（600 的标题，400 的正文）、字距（标题略收紧）和行高（标题 1.2，正文 1.7）分层。行宽控制在 30em 到 44em。

**结构要携带信息。** 分隔线、边框、编号、标签只在它们表示什么的时候出现。区块之间一条发际线就够了。

**文案也是设计。** 站在用户角度写，用主动语态，先说得到什么再说怎么做。每个元素只做一件事。失败和空状态要告诉人怎么办，不要道歉。

**动效服务于理解。** 自发动画只用在「有东西在发生」的地方：录制点的呼吸、主角的轻微浮动、查找时的跳动。响应点击的过渡可以多一点。`prefers-reduced-motion` 下全部关掉。

## 4. 工作流程：先想，再对照，再画，再挑刺

1. **写方案**：4 到 6 个命名颜色、字体与分工、版面的一句话加线框、几条原则。
2. **对照第 2 节的表**：方案里有哪一条是默认而不是选择？有就改，并写下改了什么、为什么。
3. **再动手**：先搭结构和令牌，再填内容，最后做那一个重笔元素。
4. **看成品**：浅色、深色、窄屏逐一截图，并把鼠标和键盘都用一遍。深色最容易被漏掉，这次就漏了，留作教训。
5. **减一件配饰**：出门前照镜子摘掉一件。找出最不必要的一个装饰，删掉。

## 5. 机械自查

写完用几条 `grep` 检查最容易漏的套路（把路径换成你的页面目录）。这些命令在这次的页面上都跑过：

```bash
grep -nE 'text-transform: *uppercase' styles.css
grep -noE ' [·•] |→| — ' index.html
grep -oE 'border-radius: *[0-9.]+(px|%)' styles.css | sort | uniq -c | sort -rn
grep -oE 'box-shadow: *[^;]+' styles.css | sort | uniq -c | sort -rn | head -5
grep -nE '@keyframes|animation:' styles.css
```

读法：前两条应当没有输出；圆角应当有三种以上不同数值；真正的投影最多一两种；动画不超过三处且都对应状态。

## 6. 质量底线

浅色深色都清晰；窄屏（小于 880px）改单列；所有可交互元素有可见焦点；按钮不低于 44px；状态文字用 `aria-live="polite"`；复刻的窗口用 `role="img"` 加一句描述；装饰图 `alt=""`；动画尊重 `prefers-reduced-motion`。
